# Dwelly Real-World Agents · October 2026

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache--2.0-blue)](LICENSE)
[![Event rules](https://img.shields.io/badge/Docs-Event%20rules-0D392B)](docs/rules/RULES.md)

This team workspace contains the rules, design scaffold and collaboration scripts prepared for Dwelly's Real-World Agents Hackathon in London on 10 October 2026. The team built and submitted Scale in a separate repository.

**[Open the Scale project](https://github.com/atiladeokegab/real-world-agents)** · **[Watch the submitted demo](https://github.com/atiladeokegab/real-world-agents/blob/main/video.mp4)**

The [Scale submission](https://github.com/atiladeokegab/real-world-agents/blob/main/SUBMISSION.md) records 30 unseen Banking & Financial Services cases with zero system-failure fallbacks. **MEASURED** · [Generated answers](https://github.com/atiladeokegab/real-world-agents/tree/main/ANSWERS)

## What this repository contains

1. **Read the brief.** Start with the [event and deadlines](HACKATHON.md) and the [official rules](docs/rules/RULES.md).
2. **Inspect the starting design.** The [idea scaffold](IDEA.md) and [design notes](docs/design.md) describe what the team prepared before choosing a track.
3. **Find the final build.** The [Scale repository](https://github.com/atiladeokegab/real-world-agents) contains the runnable agent, evaluations, film and submission.

## Installation

You need Git to inspect the materials. For a runnable demo, follow the [Scale quick start](https://github.com/atiladeokegab/real-world-agents#installation).
